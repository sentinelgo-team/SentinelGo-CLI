OPERATOR GUIDE / WINDOWS

SentinelGo CLI

A behavioral monitor that looks for unusual activity across Windows processes, network connections, and application events.

Run a bounded scan

On the Windows machine you want to monitor, open a terminal in the repository root with Go installed. This example runs ten collection cycles, scanning every three seconds.

go run ./cmd/sentinelgo -cycles 10 -interval 3s

Scan options

-cycles
Number of collection cycles. The default is 0, which runs until you press Ctrl+C.
-interval
Time between scans. The default is 3s.
